# make-video

영상 한 편을 처음부터 끝까지 진행하는 순서. 각 단계의 실제 일은 `.claude/agents/`의 네 에이전트가 하고, 이 스킬은 순서 · 승인 · 멈춤만 맡는다.
기준은 CLAUDE.md 4장(고정 · 참조 · 금지) · 5장(파일) · 6장(게이트). 기준문서 값은 여기 적지 않는다.

## 0. 준비

- 작업 폴더를 정한다: `out/<영상이름>/` (CLAUDE.md 5장 이름 규칙). 이미 있으면 이어서 할지 새로 할지 묻는다.
- 진행 목록(Task)을 만든다: BRIEF · 레퍼런스 정리 · 장면표 · 승인① · 스냅보드 · 승인② · 영상 · 마무리.

## 1. BRIEF (사람과 문답 → `BRIEF.md`)

한 번에 하나씩, 기본값을 같이 묻는다. 사람이 "기본값"이라고 하면 그대로 적는다.

| 항목 | 묻는 말 | 기본값 |
|---|---|---|
| 무엇을 | 이 영상으로 무엇을 보여 줄까요? (화면 · 부품 이름으로) | src/screens 01–05 흐름 전체 |
| 몇 초 | 몇 초짜리로 할까요? | 15초 |
| 레퍼런스 ① | 참고할 영상 · 문서 링크나 파일은? (최대 3개) | 없음 → 레퍼런스 없이 motion.md [기본 스타일]만 |
| 레퍼런스 ② | 그중 뼈대(구성 · 흐름을 따를 것)는? | 첫 번째 |
| 레퍼런스 ③ | 나머지에서 가져올 것은? (구성 · 구도 · 카메라 · 전환 · 글자 배치 중) | 카메라 · 전환 |

- 영상 글자(카피)는 BRIEF에 사람이 준 문장만 쓴다. 없으면 장면표 단계에서 후보를 내고 승인 ①에서 같이 고른다.
- 캔버스 · fps는 묻지 않는다 (video.md 머리말 고정).

## 2. 레퍼런스 정리 → art-director

- Agent `art-director`에게 `out/<영상이름>/BRIEF.md` 경로를 넘긴다.
- 받은 결과 `ref-notes.md`의 요약(항목 수 · 뼈대 장면 수)만 사람에게 한 줄로 알리고 넘어간다 (승인 없음).
- 레퍼런스를 받지 못했다고 하면: 사람에게 파일을 `references/`에 넣어 달라고 하거나, 레퍼런스 없이 갈지 묻는다.

## 3. 장면표 → director → **승인 ①**

- Agent `director`에게 BRIEF · ref-notes 경로를 넘긴다. director는 3안 요약을 낸다.
- 3안을 사람에게 보여 주고 하나를 고르게 한다 (AskUserQuestion, 추천안 표시). "새 후보"가 있으면 같은 자리에서 묻는다.
- 고른 안으로 director가 전체 `beat-sheet.md`를 쓴다. 고른 안 · 새 후보 답은 `decisions.md`에.
- 장면 길이가 BRIEF 길이와 안 맞는다고 director가 알리면 (motion.md 0장) 사람에게 길이를 묻는다.

## 4. 스냅보드 → builder → critic → **승인 ②**

- Agent `builder`: 장면마다 한 컷씩 `snapboard/`를 만든다.
- Agent `critic`: 스냅보드를 판정한다.
- 사람에게 **스냅보드를 먼저 보여 주고** 그 아래 critic의 한 줄 판정을 붙인다.
  - 탈락이면 사람에게 묻지 않고 builder가 고쳐 다시 → critic. 같은 곳에서 2번 탈락하면 멈추고 사람에게 묻는다 (CLAUDE.md 6장).
  - 통과면 승인을 묻는다. 고칠 말이 오면 builder → critic을 다시 돈다.

## 5. 영상 → builder → critic (승인 없음)

- Agent `builder`: 승인된 스냅보드 그대로 HyperFrames로 영상을 만들고 렌더한다.
- Agent `critic`: 영상을 판정한다. 탈락 처리는 4와 같다 (2번이면 멈춤).
- 통과하면 mp4를 사람에게 보내고 판정 한 줄을 붙인다.

## 6. 마무리

- `decisions.md`에 이번 영상에서 바꾼 [기본 스타일] · 새 후보 답이 다 적혔는지 본다.
- 사람에게: mp4 · 스냅보드 위치, 판정 한 줄, 다음에 docs에 올릴 만한 새 후보가 있으면 한 줄.
- docs/ · src/는 고치지 않는다. 바꿀 일이 있으면 제안만.
